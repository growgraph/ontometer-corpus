# Contributing to ontometer-corpus

The tables in `data/` are written by the [OntoMeter](https://github.com/growgraph/OntoMeter)
pipeline. A change to how a table is computed belongs there; this repository then receives the
rebuilt tables as a new corpus version.

Welcome here as issues or pull requests:

- corrections to the data, such as a wrong registry, licence or date for an ontology;
- licence and redistribution decisions in `data/redistribution.yaml`;
- fixes to the README.

Name the corpus commit or tag the problem was seen in.

Contributions are published under the licence of this repository,
[CC BY 4.0](LICENSE). Before your first pull request is merged, you accept the
[Growgraph Contributor License Agreement](CLA.md) once, by commenting on the pull request:

    I have read the Growgraph CLA and I accept it.
