# The paper

A paper describes the corpus, and a reader should be able to check every number in it against
the data. Its figures, tables and numbers are therefore never typed by hand: they are
regenerated by `ontometer-corpus paper` (the `paper` extra) from the tables in `data/`, the store's caches,
and two snapshots of outside data. Every number the text quotes is written as a
`\statdef{key}{value}` macro, so the text never carries a typed figure.

## Inputs

| Input | Made by | Used for |
|---|---|---|
| `data/` (`--corpus`) | the [pipeline](overview.md) | every figure and number |
| the store's cache (`--store`) | `ontometer-corpus entity-network` | the size of the term-level network |
| comparator snapshots (`--comparators DIR`) | `ontometer-corpus paper comparators fetch --dir DIR` | reuse inequality beside other reuse networks |
| GitHub sample (`--github DIR`) | `ontometer-corpus paper github plan`, `sample`, `enrich`, `recall`, `analyse`, `signals`, `baseline` (each `--dir DIR`) | the registries' coverage of ontologies published on GitHub |

Both snapshot commands download once and keep what they fetched, so a rerun reads the same
snapshot. The GitHub commands call the GitHub CLI (`gh api`, read-only), which must be
authenticated; it uses `GH_TOKEN` when that is set.

## Figures and numbers

```bash
ontometer-corpus paper figures --out DIR --corpus data --store STORE \
    --comparators COMPARATORS --github GITHUB
```

writes `DIR/<name>.pdf` and `.png` for each published figure, `DIR/stats.tex` with the
numbers, and the tables `hubs.tex`, `registries.tex` and (with `--comparators`)
`comparators.tex`. `--only NAME` draws a single figure. PDFs carry no creation date, so a
rerun on the same inputs writes the same figures.

## Deduplication audit

```bash
ontometer-corpus paper dedup-audit --out DIR --corpus data --store STORE --stats DIR/dedup_stats.tex
```

scores deduplication against the hand verdicts in `data/dedup_review.csv` and writes the
numbers as macros. `--blind-sheet` writes the judged pairs without verdicts for a second
reviewer, and `--second` scores that reviewer's sheet (agreement and kappa).

## Fonts and caches

Figures use Latin Modern when it is installed (TeX Live's OpenType files) and fall back to
DejaVu Serif. Converted fonts and the power-law goodness-of-fit bootstrap are cached under
`$XDG_CACHE_HOME/ontometer-corpus` (default `~/.cache/ontometer-corpus`).
